# Primer Monitor

[![lint](https://github.com/nebiolabs/primer-monitor/actions/workflows/lint.yml/badge.svg)](https://github.com/nebiolabs/primer-monitor/actions/workflows/lint.yml)
[![test](https://github.com/nebiolabs/primer-monitor/actions/workflows/test.yml/badge.svg)](https://github.com/nebiolabs/primer-monitor/actions/workflows/test.yml)

This is a service to allow people to register primers to be monitored for intersecting variants and be notified if new variants arise. It currently supports SARS-CoV-2 and RSV, but is capable of handling more organisms in the future if needed.
